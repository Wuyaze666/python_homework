# 必要探索性分析：计算口径与复现

本阶段对应优化顺序第2项、方案04第9节阶段2。只执行运行特征EDA、必要诊断和开发集标签探索。告警片段构造、模型训练、最终评价及正式图表/报告留在后续阶段。

## 数据与范围

- 只读复用清洗长表、未填补/有限历史宽表及逐值来源，先核验原始输入、清洗交付清单和评价准备交付清单。不重新清洗，不移动已冻结边界。
- `all_descriptive`是全文件已观测数据的描述，用于回答三车运行比较，不用于按测试结果筛选模型。
- `development`只包含固定train和validation。目标相关表仅使用开发区63801条分类候选记录；没有在目标探索链中使用test标签。读取标签文件时按source_row_id过滤，不能声称文件从未被查看。
- 10秒未填补宽表是主要比较口径，有限历史对齐为敏感性对照；原始读数分布用于检查上传频率造成的加权差异。窗口数及记录数均不等于独立样本数，也不能乘以10秒当全天运行时长。

## 输出与口径

|结果|用途和关键口径|
|---|---|
|观测覆盖、核心覆盖|分车/范围的记录、参考时刻、有效值、缺失、来源年龄及沿用数量；覆盖分母为有核心观测的参考时刻，不是全天网格|
|核心分布|5个核心变量的n、均值、样本标准差、分位数、极值及零值率；零值率分母为非缺失读数|
|速度状态|零值、正值、负值、缺失分别统计，分母为全部对应参考时刻；重复附列all5_complete是该车完整窗口总数，不能跨状态累加|
|候选怠速核对|车速=0且转速>0为候选规则；只有车速、转速同时有效才有已知判定；与IDLING的0/1观测作一致性核对，不称业务真值|
|缺失来源|区分设备未观测、片段内无历史、过期、最新无效；未填补表中仍在TTL内但超出当前窗口的来源记outside_current_window|
|配对相关性|3组关系分车计算；Spearman是平均秩的Pearson相关；少于3对或常量时为空且说明原因，不填0；无逐行独立假设的p值|
|配对明细|每对值的sample_id、两个来源source_row_id、时间与年龄、疑点标记；同时给unique_source_pairs避免沿用值被当成新独立观测|
|核心窗口来源|每个核心参考时刻的数值及源行；缺失时source_row_id可能仍指向过期或无效候选，不能把“有来源”误作“有有效数值”|
|采样间隔|同车、同变量、同既有片段内的相邻原始读数间隔；不跨片段计算；GPS不断流也可能有核心变量长断档|
|开发集较大变化索引|每车每核心变量，正时间差且不超过30秒的相邻读数，按原始数值差绝对值取前3条，附双方源行；这是数值变化排名，不是显著性检验或物理加速度|
|典型连续区间|只在开发范围，从未填补五核心同时完整的参考时刻中，选择同片段、相邻不超过10秒的最长序列，平局取最早；不挑“最漂亮”的告警案例|
|开发集变量类别计数|开发候选中实际出现的车辆×变量×类别组合，分母为该车该变量的候选总数；未输出的组合不等于业务不可能发生|
|开发集标签内分布|仅8个预定运行/状态变量，固定车和变量比较标签内原始数值；仅作为下一步关联假设，不确认类别语义|

所有数值单位及加速度轴向未获业务确认，因此保留原值，不把speed直接解释为已确认km/h，不对速度差分生成物理加速度，不认定超速、急刹或碰撞。

## 稳健性与时间约束

每组关系均保留：未填补与有限历史对齐、全部值与暂排review标记、TTL内配对与来源时间差≤2秒。2秒是预登记诊断阈值，不是通过分数优化得到的同步标准。质量对照只排除涉及变量本身的high_value_review、protocol_value_review、numeric_parse_failure来源；这些标记是疑点，不能写成已确认错误，也不删除原记录。排除后的有效n必须一起查看。

复核来源的车辆、片段、变量、时间和原始值相等，检查来源时间不晚于参考时刻。关联分析只在窗口层面解释；记录级模型仍需按真实目标时间重建过去上下文，不能直接使用窗口末状态。

## 诊断图

诊断PNG位于diagnostics，配图契约、源表位置和程序检查记录位于results。覆盖图只标记实际时间戳；原始时序遇到片段改变或相邻间隔大于30秒断开；分布图使用ECDF保留全部值；关系图按车分开，标出疑点。连续区间图按预定开发集覆盖规则选取。

这些是支持判断的诊断图，不是课程报告最终图组。按用户“报告展示最后完成”的要求，本阶段不执行论文图数、SVG/300dpi出版版式、Word/PPT/视频门禁；图的数据追溯、布局检查和实际读图仍执行。

## 运行

Python 3.12，依赖版本见项目requirements.txt。项目内.venv提供本次绘图依赖，未修改共享运行时。使用已安装相同依赖的Python，从项目根目录执行：

```text
python outputs/探索性分析/run_eda.py --self-test
python outputs/探索性分析/run_eda.py
```

第二条为完整复现入口，生成统计和诊断图。隔离复算加`--output work/EDA_独立复算`。技能原工具副本放在utils，来源为math-modeling中的plot_style、visual_qa、profile_data和repro_manifest，并在复现清单绑定哈希。

大型明细保留本地，可由代码与输入复现；统计表、图、参数、说明、代码和校验记录纳入本地Git。原清洗包与评价准备档案不改动。
