# 输入核验与评价准备：使用约定

本目录对应优化方案的第1项（方案04第9节阶段0、1）。这里只核验已有清洗、固定候选记录与评价边界，不执行EDA、告警片段识别、特征拟合、训练或最终测试。计算记录不属于最后阶段的正式报告展示。

## 观察单位与入口

- 分类对象是一条有明确变量身份的标量观测，目标为其原始alarm_class（0—5）。不取同刻最大类别，不将记录标签称为整车故障标签。
- 以source_row_id唯一连接清洗长表，排除POSITION和PIDNameNotAvailable进入分类候选；原记录仍留在清洗长表，定位仍可用于运行分析。
- 车辆沿用V1/V2/V3；变量代码按既有variable_key排序固定，只是查表键，不能作为连续数值特征使用。模型的类别编码、填补与筛选仍须只在训练集拟合，未知变量需支持未知类别处理。
- `results/候选样本索引.csv`给出记录级固定归属，不复制测量值或标签；`变量编码.csv`和`车辆编码.csv`提供查表关系。
- `状态样本分析范围.csv`给出3132个既有10秒参考时刻的分析范围。它适用于宽表EDA，不能直接用于记录级模型的当前上下文，因为窗口结束时可能晚于目标记录。
- `观测片段划分.csv`覆盖全部44个既有片段，包括没有分类候选记录的GPS片段。全长表按vehicle、segment_id连接它，目标相关EDA只取train/validation。全样本描述另行标注，不作为调参依据。

## 固定划分算法

1. 沿用清洗阶段按全长表相邻观测间隔大于300秒划分的观测片段，不重新定义片段来改善指标。
2. 每车按时间排序，完整片段只能属于一个集合。至少有3个含候选样本片段时，枚举两处切点，保留早期训练、中期验证、晚期测试；以记录数相对60%/20%/20%的绝对偏差之和最小为准。平局取最早训练切点、再取最早验证切点。比例只是目标，完整性优先。
3. 两个候选片段时，早段训练、晚段测试，不建立该车验证集。只有一个时仅供训练、没有该车内部留出评价。当前数据的实际例外由汇总表记录。
4. 算法只接受身份、时间、片段与数量；完成边界生成和登记后才查看各类支持数。不得因类别缺失、样本难度或后续模型分数移动边界。
5. `冻结边界.json`绑定清洗长表、规则文件哈希和所有片段归属。再次运行如边界不同则报错，后续确需修改必须另存版本并说明原因，不能覆盖已有实验依据。

## 历史与告警边界约束

- 最大原始历史统计窗口60秒，最大过去状态有效期60秒，预留120秒覆盖潜在叠加回溯。边界检查用左右完整片段的最后／首次原始观测，要求间隔严格大于120秒；恰好120秒也拒绝。代码不自动削减隔离带或把失败记录搬到训练集。
- 特征只能匹配同车同片段、时间不晚于目标记录的原始观测，不使用任何历史标签。绝对时间、车辆身份、source_row_id、segment_id、episode_id及标签派生统计不进入模型。
- 后续特征若扩大回溯范围，必须重新核验冻结边界能覆盖新范围，不能默认已通过。
- 告警合并规则必须限制在同车、同变量、同观测片段内。因此本次完整片段分区从结构上阻止告警片段跨集合，目前没有额外边界剔除。告警尚未实际生成；生成后仍须按episode_id核对集合唯一性。若发生跨界，剔除整个边界告警片段，保留原始split并记录剔除原因与source_row_id，不挪动样本。
- 候选记录不等于所有特征组最终都能用的样本。缺失值处理先保留记录；后续若确需排除，单独记录，A/B/C比较应声明共同样本口径。

## 评价范围与后续使用

- 主评价是“各车后期片段”的内部时间留出，各车切分日期不同，不代表所有车辆共用一个日历截止点的未来部署实验。原数据质量诊断及全量标签计数已被查看，不能称完全未接触的外部盲测。
- train用于拟合；validation用于选择变量、模型和参数；test在方法冻结后评价。测试后的错误分析用于解释，若据此改模型需新增实验版本并披露测试已参与迭代。
- 类别支持数只说明可评价性。没有样本的车/类别写不可评价，不虚构分数；不能把V3缺少验证样本写成有独立三份数据。后续主指标与逐类支持数一同输出。
- `留一车辆预登记.csv`固定补充实验：留出车的全部候选为测试；其他车的主train为训练、主validation为验证、主test不用。它检验未见车辆迁移，不能与主时间测试混成一个成绩。测试车不用于选择特征、事件阈值或参数；这类选择仅在其他车开发数据内重新完成，或使用事先固定且不依赖目标车的规则。执行顺序放在主模型方法及结果冻结之后。
- 输入核验复用了清洗阶段已通过的未来匹配/来源追踪验收，核对归档字节一致；本阶段没有声称重新全量复跑清洗。

## 复现与验收

从项目根目录执行（Python与依赖见项目requirements.txt）：

```text
python outputs/评价准备/prepare_evaluation.py --self-test
python outputs/评价准备/prepare_evaluation.py
```

第二条为唯一实际准备结果复现命令。隔离复算可加`--output work/评价准备复算`，不改权威结果。原始HTML/CSV仍需位于输入来源清单所列位置；缺失或哈希不符会停止，不跳过。

输入与清洗归档核验见`输入哈希核验.csv`；行数、字典、片段、时间隔离等检查见`准备验收.json`；计算产物哈希见`输出哈希.json`；环境与命令见`复现清单.json`。复现清单的生成时间及本机路径属于运行元数据，不参与结果等价比较。独立复核记录另存于本目录。
