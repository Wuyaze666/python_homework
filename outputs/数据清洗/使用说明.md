# 车辆物联网遥测数据清洗

## 使用入口

`results/清洗长表.csv` 是后续分析的主数据。`results/状态宽表_10秒_有限历史对齐.csv` 用于比较同一参考时刻的车辆状态；需要严格观察原始覆盖情况时，使用对应的未填补版本。`results/告警观测表.csv` 只包含非零标签记录，正常记录仍完整保留在清洗长表。

所有 CSV 使用 UTF-8 BOM 编码，Excel 和 pandas 均可读取。空单元格表示缺失或不适用，不代表0。读取原始字符串字段时建议 `pd.read_csv(..., dtype=str, keep_default_na=False)`；数值分析只转换需要的派生列。

## 已执行规则

- 原始文件只读；清洗长表保留六个原始字段，`source_row_id` 从1开始对应原始数据行，实际文本行号为此值加1。
- `time_local` 直接解析原始timestamp。根据全部已知时间对观测到的固定+05:30偏移构造 `time_utc_inferred` 和 `time_mili_clean`。后者单位为Unix毫秒，原本缺失由 `time_mili_was_missing` 标记。UTC时间为数据内一致性推断，不作为来源时区的官方确认。
- 按设备、时间、原始行号稳定排序。全量原始数据没有重复键，未删除任何记录。若换用新文件出现重复键，脚本会停止，避免未经解释地聚合。
- 定位拆为纬度、经度、海拔；零占位0,0,0只在派生坐标中置空，原始坐标及其他传感器保留。
- 未知PID记录保留原始值及数值解析结果，但不进入状态宽表。可匹配正式定位的记录保存 `matched_position_row_id`，定位轨迹仅取正式POSITION，避免重复计数。
- 连续值、二值状态、代码和计数器分别记录类型；不统一截尾、不标准化、不用均值填补。
- 按全部观测的相邻时间间隔大于300秒建立观测片段。片段不是行程，也不表示片段内每种传感器持续在线。
- 原始告警类别不改写、不插值。告警观测表不是合并后的事件表；本次不推定真实事件起止和故障成因。

## 10秒宽表的时间含义

样本只覆盖至少有一次车速、转速或三轴加速度观测的10秒窗口，不将全周GPS区间扩张成稠密OBD样本。

窗口为 **(reference_time−10秒, reference_time]**，左开右闭。整10秒时刻的记录属于以该时刻结束的窗口。例如10:00:10的记录属于(10:00:00,10:00:10]。这与前期诊断采用向下取整的左闭桶边界不同，窗口数量和覆盖数可能不同，正式结果以此明确规则为准。

宽表每个数值表示该变量截至参考时刻最近的一次观测，不是窗口均值、中位数或同时采样值。最后一个参考时刻可能略晚于片段最后一次观测，但只能使用该片段内已有历史记录，仍受时效限制。

- 未填补版：最新观测须在该10秒窗口内，且值有效。
- 有限历史对齐版：只使用同车、同片段、不晚于参考时刻的最后观测；核心5变量有效期10秒，部分变化较快变量20秒，其余已知标量变量60秒，定位10秒。
- 匹配的是最后一条记录，即便该条定位无效，也会阻止绕过它继续沿用更早的有效坐标。
- 这些有效期是保守的初始工程参数，未验证为设备协议规定的保持时间。常量字段也不无限延续。
- 不使用未来值，不跨片段，不对标签填补。没有使用全数据拟合统计填补器。

`状态宽表_逐值来源.csv` 每行对应一个“样本×特征”，包括来源行号、采样时间、年龄、有效期、是否可用、是否沿用上一窗口数据。即使候选值已过期，该表仍保留候选用于审计；**只有 available=1 的候选进入有限历史对齐宽表**。

状态解释：

|status|含义|
|---|---|
|not_observed_on_device|此设备全文件未观测到该变量，不能据此确定没有硬件配置|
|no_history_in_segment|当前片段截至参考时刻尚无该变量读数|
|expired|最后读数已超过有效期|
|invalid_latest_reading|最后读数无效，例如零定位|
|observed_in_window|有效读数在当前窗口内|
|carried_from_past|有效读数来自更早窗口，但未超过有效期|

## 告警窗口的含义

`告警窗口_10秒.csv` 覆盖全部原始记录中至少有观测的窗口，而非仅核心变量窗口。每类记录数以及类别1—5是否被观测到分别保存，支持多类并存。`no_alarm_in_observed_records`仅表示已观测记录没有非零标签，不能解释为整车正常。不存在观测的窗口不创建行，应理解为未知；不能自动补成正常。不同变量的0标签不覆盖其他变量的非零标签。

后续按设备、变量及类别合并事件，需要另行定义事件间隔和终止规则。本次清洗保留所需信息，不提前作未经验证的事件合并。

## 疑点标记，不是删除条件

|标记|本次规则|处理|
|---|---|---|
|altitude_review|海拔原始值小于−100或大于500|保留，不认定负海拔必错|
|high_value_review|转速原始值大于6000，或车速原始值大于150|保留；单位未独立核实，阈值仅供复核|
|protocol_value_review|累计距离值65520；暖机计数255或2.5|保留，不擅自定义为协议缺失码|
|counter_decrease_review|同车、同片段、同计数变量相邻值下降|保留，可能为复位|
|gps_jump_review|相邻有效定位间隔0—10秒，球面距离推算速度大于200km/h|保留并提供距离/时间差；阈值仅作疑点筛选|

GPS距离以地球半径6371000米计算，仅作粗略诊断。中间出现无效定位或长间隔时不跨越连接，也不据此修正OBD车速。疑点计数可重叠，不能相加视为坏行数。

## 复现

安装Python及pandas、numpy后，在本目录运行：

```text
python clean_telemetry.py --input "题2_车辆物联网遥测 (1).csv"
```

输入文件可使用任意实际路径；默认结果写入脚本旁results目录。同名结果会更新，因此如需保留旧版本，请指定不同的 `--output` 目录。所有参数集中在脚本开头 `PARAMS` 中。输入哈希及本次环境版本见复现清单和验收文件。

`--limit`和`--skip-sensitivity`仅用于快速验证；正式重现不要加这两个选项。包内不重复包含原始CSV，请使用用户已提供的原文件并核对SHA-256。
