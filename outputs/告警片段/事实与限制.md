# 任务3计算事实与后续约束

这是实际计算的证据笔记，非正式课程报告。以下类别仍沿用0—5原始编码，数值单位与业务语义未确认，不把某类命名为超速、碰撞、怠速故障或部件损坏。

## 2. 标签与数值区间有很强对应，但存在车辆差异

开发范围内，车速在V1/V2/V3分别有79/4/89个不同值，转速有203/7/181个不同值；**在车速与转速中，同车、同变量、同数值没有出现多个标签**。这是观测一致性，不能证明未观测到的取值也必然遵守同一规则。

例如车速的相邻已观测取值：

- V1：19→20时类别1→2，29→30时2→0，50→51时0→3，70→71时3→4。
- V3：9→10时1→2，19→20时2→0，30→31时0→3，40→41时3→4。

类别编码不是可以按大小直接解释的风险严重程度。正常类在某些中间数值区间出现；非零类也会出现在较低读数。

V1与V3共同观测到79个车速值，其中60个值对应不同标签集合；共同观测到155个转速值，其中126个不同。此比较单位是不同取值，不是记录行数，不能当分类错误率。

由此形成的解释假设是：标签可能包含按变量、车辆配置的分档规则；也可能受设备配置、数据生成方式或未见业务状态影响。后续先检验仅用变量和当前值的A组参照，再比较上下文增益。不得因为此现象直接加入设备ID捷径，也不得把良好分类分数解释成已识别真实故障成因。是否能跨车泛化仍需后续留一车辆验证。

## 3. 跨变量状态关联：有支持数，也有缺测和疑点限制

以车速游程起点的转速为例，class0对照是正常游程起点：

|---|---:|---:|---:|
|V1|0|1090|281/281|
|V1|1|850|271/271|
|V1|2|1100|219/219|
|V1|3|1740|26/26|
|V1|4|2065|8/8|
|V3|0|1355|16/16|
|V3|1|850|21/21|
|V3|2|1290|18/18|
|V3|3|1455|16/16|
|V3|4|1840|39/39|

V1类别3/4、V3类别4的车速片段起点通常伴随较高转速，但这是状态关联。V1类别4仅8个起点，不能夸大稳定性；正常类包含多个数值区间，也不能简单说正常与告警两群完全分开。

V2车速类别4的5个起点都匹配到转速，转速中位数9000，且5个匹配值全部有既有高值复核标记。年龄≤2秒且暂排疑点后有效数变为0/5，因此不能把这组明显差异当成已确认的机械异常证据。

开发范围V2共7条高车速、13条高转速疑点，形成车速5段、转速8段；均在validation。车速片段首末跨度0—60秒，转速0—69.288秒，多处断档使边界不确定。可能是实际高读数，也可能涉及编码、缩放、设备配置或测试数据，现有资料不能排除；保持原值与标记，不删除、不强行修正。具体源行见`V2疑点记录追踪.csv`。

IDLING=0在V1出现453条、V3出现77条，都同时对应class0和class5，因此该变量的当前值不足以完全解释其类别。V1 class5游程起点205个，有197个能比较车速/转速，仅1个满足“车速=0且转速>0”；V3为18个起点、16个可比较，0个满足。不能将class5或IDLING字段名直接解释为车辆实际怠速。

## 4. 类别共现随时间桶变化

例如V1类别1与2：

- 10秒窗中交集1570桶、并集1991桶，Jaccard约0.7885。
- 精确时间口径明显更低（约0.49，精确分子分母见结果表）。

V3类别2与3在10秒窗中交集288桶、并集371桶，Jaccard约0.7763。扩大时间桶会把不同时间的观测放到一起；同一变量在窗内切换类别也会贡献共现。不能据此推断某一类触发另一类，或把多类合并成唯一整车状态。

## 5. 三个可核查案例

案例的前后窗口是描述性查看，不作为预测特征；后续模型特征仍只能使用记录当时及以前的数据。

### E057833：V1车速从正常区间进入类别3

2020-08-18 10:29:57，源行57833，车速53、类别3；5秒前源行57818为47、类别0。本段共18条同类观测（含首条），首末跨度96秒，末源行58052；下一次观测9秒后变为正常类。前后图只展示首观测±60秒，完整边界另见`案例边界证据.csv`。

起点转速源行57830为1090，5秒前为1600，随后又上升。车速标签切换与其数值区间对应，转速并非在切换瞬间同步升高；因此不能用“发动机转速上升导致告警”作确定解释。设备按车速区间分档是可检验假设，真实故障、危险驾驶和道路超速都没有足够证据。

### E160565：V3类别4短段及类别来回切换

2020-08-21 16:43:56，源行160565，车速41、类别4；5秒前源行160553为39、类别3。3秒后源行160579仍为41、类别4，之后2秒源行160607变成25、类别0。本段只有2条，观测跨度3秒。

起点同刻转速1800，随后在车速25时转速820。短时间读数下降和标签切换是真实文件现象，但不能在单位、采样与设备含义未确认时认定急刹车或碰撞。窗口更早也出现过类别4，中间类别3切断了同类片段，不能把前后同类直接合并。

### E107579：V1 IDLING同类断档造成新片段

2020-08-19 16:38:17，源行107579，IDLING=0、类别5；当时车速39、转速1140，均有同刻来源。前一条IDLING在48秒前已是类别5，后一条60秒后仍是类别5；V1该变量合并阈值40秒，因此本次形成两端不确定的单点片段。

这不是已确认的新故障开始，也不是看到恢复正常后再报警；只是在断档后再次观测到同类。窗口中更早的−58秒IDLING=1/class0，−53秒变成0/class5，可观察到一次标签转换，但不能把中间未观测时段补成确定持续的class5。

该例车速/转速前后读数密集，IDLING却稀疏，证明核心信号连续不保证全部变量连续。它也解释了单点片段较多的一部分来源。

三例窗口均有36条定位记录，已有零定位、GPS跳变、计数器下降标记计数均为0；这只说明已定义的检查未命中，不能排除未识别的数据问题。其他字段仍有4/4/6条协议值复核标记（按上述案例顺序），保留在案例证据中；核心车速/转速无高值复核标记。未把整个窗口无条件视为“完全正常的数据”。

## 6. 进入建模阶段的约束

1. 保持记录级六分类、冻结分区、V3无验证的事实；不重新随机切分。
2. 以变量/当前值、过去可用状态、历史变化三组逐步比较，先做简单参照；当前尚未训练任何模型。
3. episode_id只用于错例回看和片段检出覆盖，不进特征；完整片段的末时刻、跨度、未来记录数同样不能进特征。
4. 不能用类别整数大小解释严重程度；不能把同刻不同变量的标签压成一个整车类别。
5. 继续记录V2疑点、设备差异和缺测影响；不从这些内部描述直接提出维修、更换部件或驾驶行为判罚。
6. 正式报告、汇报图、PPT与视频在计算和模型验证完成后统一整理。
