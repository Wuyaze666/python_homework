# 任务5：有依据的特征扩展与有限调参

本目录对应方案04第9节阶段5。只在原52892条训练记录和10909条验证记录上开发；19662条测试记录保留给阶段6。本阶段不合并训练/验证重新拟合，不开展跨车留出，不制作正式课程报告。

## 依据与实验顺序

任务4的RF有467条class0→5误报，全部来自TOWING、IGNITION STATUS、IDLING的当前值0；相同A输入存在多标签。该证据支持检验当时的车辆状态是否提供额外信息。类别权重可能影响取舍，因此保留A组无权重对照，不将误报先验归因于权重。

`参数.json`在全量运行前写定。RF保持200棵树、深度16、叶最小3、sqrt特征数、种子42；先复算A组并逐行核对任务4预测和概率，再分别比较A无权重、B状态值、B状态值加年龄。浅树的深度8、叶最小10、balanced沿用任务4，只作解释性比较。

特征增量至少使验证六类Macro-F1提高0.005，且V1/V2有支持类别Macro-F1、总体正常类召回相对父方案下降均不超过0.02，才接受。B接受后，若三个二值变量仍有至少20条错误，再测试C30；C30接受后才测试追加C60。以上是本次预登记的工程筛选界限，不是统计显著性或外部通用标准。

在接受的特征方案上分别只改一项：取消类别权重、叶最小样本量改10、树深改24。每项与该特征组固定RF比较，不组合成大网格，也不重复运行已有的A无权重实验。

推荐范围为已经接受的特征组及其RF参数候选；正常类召回及V1/V2有支持类别Macro-F1不得比A初始RF低超过0.02。在最高验证Macro-F1的0.002范围内，优先总树节点更少者，再依编码特征数、模型名称打破平局。被拒绝的特征扩展保存结果，但不通过最终推荐步骤重新混入。浅树只作比较，不加入这轮RF调参排序。

推荐后用43、44两个附加种子重复推荐配置和A基线，用于观察随机性，不再据此更换候选。三个种子复用同一验证集，不是三个独立数据集，不能据此给出泛化置信区间。

## 特征与时间边界

A沿用变量身份、类型及当前值。binary/code以离散token编码，其他变量的缺失当前值用该变量训练中位数，不能跨变量混合单位。

B增加10项状态：车速、发动机转速、三轴加速度、节气门位置、发动机负荷、IDLING、IGNITION STATUS、TOWING。前8项延续任务3状态关联，后2项直接对应任务4错例。每个目标源行在真实时间t按同车、同观测段寻找时间≤t的最新原始读数，使用既有清洗字典的TTL；最新无效读数会阻断更早有效读数。无历史、过期或最新无效均留缺失，不跨段填补。模型不输入车辆、绝对时间、源行或片段编号。

B_values仅加状态值及其必要缺失编码。B_age再加可用状态的采样年龄；过期或无效状态的年龄不输入模型。二值状态仍作类别编码。这里假设同刻各信号批次已可用，不能宣称逐条流式接收时必然可得；另用排除同刻其他变量的压力测试核验这种依赖。

C使用严格过去区间[t−30秒,t)；通过后追加[t−60秒,t)。车速/转速分别计算有效数、无效数、最后有效采样年龄、均值、总体标准差(ddof=0)、最小值、最大值、首末有效值差/真实时间差。少于两个不同时间点时变化率为空。三项二值状态只算有效数、无效数、最后有效采样年龄及相邻有效原始记录的状态改变次数；无效读数两侧不跨越计数。不平均离散状态，不使用标签或历史告警类别，也不把沿用值当作多条观测重复统计。状态改变次数是在窗口中实际观察到的变化，不是完整真实切换次数；时间和单位未经业务确认，变化率不解释为真实物理加速度。

各通道使用原始量纲，数值中位数及独热词表只在训练记录拟合。连续上下文缺失填各列训练中位数，全缺失列回退0，并始终加缺失指示；未知类别使用训练词表的ignore规则。缺失、年龄和观测数可能携带采样机制或车辆差异，不能因为不输入车辆ID就声称彻底消除了身份影响。

## 验证与敏感性

所有实验使用完全相同的冻结记录，保存训练表观拟合和验证的逐类/逐车指标。正常/告警二分类是0对非0的折叠。无真实类别支持时召回/F1留空；V2缺class5、V3无验证样本，继续如实保留。概率未校准，不能当真实故障风险。

对推荐的同一个已拟合模型、同一验证记录另做推理压力测试：B状态年龄≤2秒；屏蔽带既有质量复核标记的B状态及受标记读数影响的C特征；排除同刻其他变量。压力测试不重新拟合、不重新选模型，因此可能形成训练时较少出现的缺失组合；它衡量依赖程度，不等于公平重训消融或删除疑点后的无偏性能。目标当前A值始终保留。另分组报告目标记录自身的质量标记及错误数，不删除困难样本。

## 复现与文件

在项目根目录、requirements.txt规定的Python环境中运行：

```text
python outputs/特征扩展/run_extension.py --self-test
python outputs/特征扩展/run_extension.py --smoke
python outputs/特征扩展/run_extension.py
```

独立复现可追加`--output work/特征扩展_独立复算`。该选项只允许新阶段目录或work子目录，防止覆盖既有阶段归档。未改变原始文件和任务0—4目录。历史及状态来源检查同车、同段、同冻结分区及时间边界；A复算必须与原模型验证预测一致。

`results/实验台账.csv`记录每次实验的参数、种子、规模和指标；`特征增量决策.csv`记录接受/停止依据；`开发候选推荐.json`只给阶段6准备候选，尚未宣称最终测试能力。`验证预测.csv`保存每行类别/概率/错误回查字段；episode_id仅用于追溯。`状态来源.csv`、可能生成的`历史来源.csv`、`开发特征.csv`以及验证预测为大型可复现文件，保留本地并通过哈希索引，忽略Git。推荐模型joblib同样保留本地，加载时需将本目录及`outputs/建模实验`加入Python模块路径，且只加载可信的本地文件。

`results/输出哈希.json`核对确定性计算产物，`results/复现清单.json`记录输入、脚本、版本和命令（运行时间不同，不作逐字节复算比较）。正式图表配额及出版导出按用户要求后置，本阶段只保存帮助核验结果的诊断PNG及图表契约。
